MULTI-VOLUME STRATEGY

For projects with
multiple volumes.

Example: 28-track project broken into 4×7. You have two clean options — pick based on how you want it shared.

OPTION A • RECOMMENDED4 LINKS
Separate Players Per Volume
Treat each volume like its own album. Best for sharing, clean URLs, smaller uploads.
28-Tracks-Vol-1/ → index.html + cover.jpg + 7 mp3s
28-Tracks-Vol-2/ → ...
→ ajosephowens.github.io/28-Tracks-Vol-1/
→ ajosephowens.github.io/28-Tracks-Vol-2/
Run make-all-projects.bat — it generates tracks.json for all 4 at once.
OPTION B • ONE LINK28 TRACKS
One Player, Sectioned Titles
Put all 28 in one repo. Use filenames to show volumes.
28-Tracks-Complete/
01 - Vol 1 - Track 1.mp3
08 - Vol 2 - Track 1.mp3
→ Continuous play through all 28
Good for a single “full experience” link. Trade-off: bigger repo, less shareable per volume.
